# 实验来源与故障说明

本项目在本轮开发，实际用途是统计构建日志中的诊断行。它不是从课程自动生成的
`integration-sample` 复制出来的项目。作者身份使用学号 241880331，Git 时间使用实际提交时间。

## 两个开发版本

- `e12-base`：v0.1 基础工具，支持小写 warning/error、文件和标准输入、JSON、颜色日志、长行。
- `e12-target`：v0.2 新增大小写兼容、note 统计和 `rules.h` 配置。为验证增量构建缺陷，
  **在该实验版本人为保留 `helper.o` 对 `rules.h` 的漏声明**。

新增功能是本轮实际实现的功能变更；漏依赖是本轮明确注入的受控故障，不能描述成历史生产事故。
两个版本均应能在工具链齐备的环境中干净构建。目标版本的普通功能测试可通过，但改变
`LOG_STATS_COUNT_NOTES` 后会错误复用旧 `helper.o`。补上依赖后应正确重编译，note 数从 2 变成 0。

目标版本预期唯一 MD：`helper.o -> rules.h`。本项目没有刻意添加冗余依赖。

## DRAFT 场景

`Dockerfile.broken` 使用未安装 make 的 Python slim 基础镜像，第一轮应复现 `MISSING_MAKE`。
候选保持同一基础镜像标签、COPY、构建和 CMD，固定基础镜像摘要并安装工具链。
该 Dockerfile 故障同样是本次实验准备的受控故障。
